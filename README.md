# Experiments for the rebuttal of NeurIPS26

The repo consists of the following folders:

-``Baselines``: heatmaps of 2 additional baselines, i.e., [Duan et al., 2021; Long et al., 2022], examined on ImageNet and CIFAR100, similar to the ones depicted in Fig. 3, 5-6 of the manuscript, following the corresponding attack levels. Specifically, ``asr_imagenet_ssa_advdrop.png`` and ``asr_cifar100_ssa_advdrop.png``  pertain to ASR values of the additional baselines, when evaluated on ImageNet and CIFAR100, respectively, similarly to Fig.3, while ``asr_cifar100_ssa_advdrop.png`` and ``asr_imagenet_ssa_advdrop.png`` pertain to ASR values of the additional baselines, when evaluated on ImageNet and CIFAR100, respectively, similarly to Fig.5 and 6, respectively. Additionally, ``updated_visual_comparisons_imagenet.png`` and ``updated_visual_comparisons_imagenet(spectra)``.png pertain to the updated Fig. 1a and 1b, to also include a visual, for expository purposes, comparison of our method to the two new baselines. For all experiments, we use the Github repos and set the best hyperparameters proposed by Duan et al. and Long et al.

-``Settings``: code accompanying all our experiments, both those reported in the paper, as well as those asked during the rebuttal period. To run all the experiments, the user runs the script run.py, which downloads all the models and runs our proposed method, as well as all four baselines, for ImageNet and CIFAR100; the data must also be stored as ./data.
