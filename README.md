# Experiments for the rebuttal of NeurIPS26

The repo consists of the following folders:

-``Baselines``: heatmaps of 2 additional baselines, i.e., [Duan et al., 2021; Long et al., 2022], examined on ImageNet and CIFAR100, similar to the ones depicted in Fig. 3 of the manuscript, following the corresponding attack levels. Specifically, ``asr_cifar100_ssa_advdrop.png`` pertains to ASR values of the additional baselines, when evaluated on CIFAR100, while ``asr_imagenet_ssa_advdrop.png`` pertains to ASR values of the additional baselines, when evaluated on ImageNet. For all experiments, we set the best hyperparameters proposed by Duan et al. and Long et al., while the attack level follows the one of Fig. 3 of our manuscript.

-``Settings``: code accompanying all our experiments, both those reported in the paper, as well as those asked during the rebuttal period.
