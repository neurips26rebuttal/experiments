# Experiments for the rebuttal of NeurIPS26

The repo consists of the following folders:

-``Baselines``: heatmaps of 2 additional baselines, i.e., [Duan eta al., 2021; Long et al., 2022], examined on ImageNet and CIFAR100, similar to the ones depicted in Fig. 3 of the manuscript, following the corresponding attack levels.

-``Settings``: code accompanying all our experiments, both those reported in the paper, as well as those asked during the rebuttal period.
