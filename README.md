# Experiments for the rebuttal of NeurIPS26

The repo consists of the following folders:

- ``Baselines``: heatmaps of 2 additional baselines, similar to the ones depicted in Fig. 3 of the manuscript.
- ``Stds``: standard deviations, given in tabular form, corresponding to the ASRs of the heatmaps of Fig. 3 of the manuscript.
- ``Table``: updated Table 1 of the manuscript, to include the stds from the heatmaps of the folder ``Stds``
- ``Runtimes``: runtime per image, given in tabular form, for each of the attack-dataset-model pair
